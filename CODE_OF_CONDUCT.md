# Code of Conduct

This project is for practical, respectful collaboration.

## Expected Behavior

- Be clear and constructive.
- Keep discussions focused on the project.
- Do not post private medical, personal, server, or Telegram credential details.
- Assume good intent, but be direct when something is unsafe or incorrect.

## Unacceptable Behavior

- Harassment or personal attacks
- Sharing another person's private information
- Posting real bot tokens, chat ids, passwords, or server credentials
- Encouraging abusive traffic against third-party services

## Reporting

Open a GitHub issue for project conduct concerns, or contact the repository maintainer privately when public discussion is not appropriate.
